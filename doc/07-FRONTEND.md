## 7.3 Dashboard
Display:
- total hospitals
- total beds
- population
- underserved population
- critical areas
- latest demand prediction
- latest optimization run

## 7.4 GIS Explorer
Layers:
- hospitals
- population density
- roads
- accessibility
- underserved zones
- predicted demand
- candidate sites
- recommended hospitals

Features:
- zoom
- pan
- layer toggle
- legend
- popup
- search
- bounding-box loading
- map click
- export

## 7.5 Accessibility screen
Controls:
- analysis name
- geography
- travel mode
- weights
- run analysis

Results:
- KPI cards
- map
- distribution chart
- underserved-area table

## 7.6 Demand screen
Show:
- model version
- validation metrics
- feature importance
- predicted demand map
- forecast table

## 7.7 Optimization screen
Inputs:
- number of hospitals
- objective weights
- constraints
- algorithm parameters

Output:
- candidate map
- selected sites
- ranking
- population served
- travel time
- accessibility improvement
- explanation

## 7.8 UX requirements
- loading states
- empty states
- error states
- confirmation dialogs
- accessible forms
- responsive layout
- clear units
- map legend
- color-blind-friendly visualization

Do not use map colors as the only indication of risk/accessibility; include labels or tables.
