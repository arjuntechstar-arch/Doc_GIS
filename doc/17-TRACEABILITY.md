Dataset D-DEMO is internally generated by `demo.py` and has no external provider or license. It is labeled synthetic in the database and UI. OpenStreetMap is used only for a third-party basemap tile layer; imported road and hospital data are independently provided by the operator. The database uses MongoDB GeoJSON and `2dsphere` indexes for authoritative WGS84 geometry; Shapely and pyproj handle projected centroids and constraints, and NetworkX handles travel graphs because MongoDB has no road-routing function. The GA uses selection, crossover, mutation and elitism to search combinations where exhaustive enumeration is impractical. Its outcome depends on imported roads, land constraints, demand model, configuration and simplified site costs.
